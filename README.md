# Tech Stack

## Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

## Backend
- Express
- TypeScript

## Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:leobenTaningco/yet-another-notes-app.git
cd yet-another-notes-app
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Install backend dependencies

```bash
cd ../backend # if coming from /frontend
cd backend # if coming from root directory
npm install
```

### 4. Start the backend

```bash
# while in backend directory
npm run dev
```

The backend runs on:
```http://localhost:3001```

### 5. Start the frontend

```bash
# while in frontend directory
npm run dev
```

The frontend runs on:
```http://localhost:3000```
